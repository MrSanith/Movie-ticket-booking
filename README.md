
# Movie Ticket Booking System

A full-stack Movie Ticket Booking System built using PHP,
MySQL/MariaDB, HTML, CSS, and JavaScript.

## Project Overview

This project aims to provide a secure, responsive, and
user-friendly online movie ticket booking platform.

The application is being developed using a structured
approach with version control and incremental testing.

## Planned Features

### Customer Features
- User registration and login
- Browse available movies
- View movie details and showtimes
- Interactive seat selection
- Ticket booking and checkout
- Payment gateway integration
- Booking confirmation
- Booking history

### Admin Features
- Admin authentication and authorization
- Movie management
- Showtime management
- Theatre and seat management
- Booking management
- Dashboard and reports

## Technology Stack

| Component | Technology |
|-----------|------------|
| Frontend | HTML, CSS, JavaScript |
| Backend | PHP |
| Database | MySQL / MariaDB |
| Database Access | PDO |
| Local Server | XAMPP / Apache |
| Code Editor | VS Code |
| Version Control | Git and GitHub |

## Project Structure

- `app/` - Backend application logic and views
- `bootstrap/` - Application initialization
- `config/` - Configuration files
- `database/` - Database migrations
- `public/` - Public entry point and static assets
- `routes/` - Application routes
- `storage/` - Private application files and logs
- `tests/` - Automated tests

Environment files, private tickets, logs, and local
credentials must not be committed to Git.

The production application will use a dedicated public
document root, secure database access, and appropriate
authentication and authorization controls.
